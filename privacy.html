Privacy policy

Last updated: 12 November 2026

Lead Finder is a private tool used only by its owner, Nichita (contact: nichitaob@gmail.com). It has no other users.

What Google data it accesses

It uses the read-only Gmail permission (gmail.readonly) on the owner's own account only.

This permission technically allows reading the whole mailbox. The program itself limits what it reads: it asks Gmail only for notification emails sent by Facebook, LinkedIn and Google Alerts, and downloads only those.

These are notifications the owner receives about posts he can see, for example in groups he is a member of. The program does not check whether a post is public.

It never sends, deletes or modifies emails.

How the data is used

On the owner's computer, each notification is filtered: only requests for services (for example "looking for someone to build a website") are kept; everything else is discarded without being stored.

The kept text is cleaned: the author's name, commenters' names and bank or card details are removed.

The cleaning is automatic and may miss some details.

Who receives data

Anthropic (Claude AI). Only if the owner turns this on for Gmail, the text is sent to Anthropic to classify the request, translate it or draft a reply. Names and contact details are first replaced with placeholders such as [AUTHOR] or [PHONE_1].

Telegram. The owner receives short alerts in his own private Telegram bot. When he presses a button, he also receives the cleaned text, the link to the post and any translation or draft reply, so he can decide himself whether to answer.

Nothing is sent to anyone else. The data is not sold and not used for advertising.

Storage and retention

The data is stored in an encrypted container on the owner's computer.

Notification texts are deleted from the working database after 3 days. Daily encrypted backups are kept for 30 days; when a backup is restored, deletions made after it are applied again.

Clean-up runs while the program is running; if the computer stays off, it happens when the program starts again.

Telegram alerts are deleted after about 47 hours. If the owner's computer is off for longer, the deletion happens later or is done by hand.

The original notification emails stay in the owner's Gmail until he deletes them; the program does not delete emails.

The long-term Gmail authorization (refresh token) is kept in the Windows Credential Manager; the short-term access token is kept only in memory. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Lead Finder's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your rights

If you appear in a notification and want your data removed, or want to object, write to nichitaob@gmail.com.
